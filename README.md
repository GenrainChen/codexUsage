# Codex 用量便签

Windows 桌面小窗，展示本机 Codex 每日／每周／每月、每个模型的输入／缓存／输出 token，以及按公开 API 标准刊例价换算的美元金额。可以置顶、拖动和缩放，按北京时间每小时的 00、05、10……55 分自动刷新。

使用橙色折角便签图标。Windows 11 的标题栏与内容采用相同的暖白底、深色文字，保留系统窗口交互；其他系统沿用系统标题栏。图标源文件与多尺寸 ICO 位于 `assets/`，可运行 `scripts/build-icon.ps1` 重新生成，不需要额外依赖。

## 打开

双击 `start.vbs`，或桌面的「Codex 用量便签」快捷方式。拖动系统标题栏移动，拖动窗口边缘缩放，使用窗口内的置顶按钮让它常驻屏幕。关闭窗口即退出。

窗口移动或缩放停止约 0.4 秒后，会自动保存位置和大小；正常关闭时再保存一次，下次启动恢复。最小化或最大化时关闭，会保留之前普通窗口的位置和大小。

便签统一使用 **北京时间（UTC+8）**。顶部切换「日／周／月」，会记住上次使用的视图。日期旁的左右箭头按当前单位翻页，点击日期可输入区间内任意日期，右侧按钮回到今日／本周／本月。顶部卡片显示整个区间的消费或产出，下面滚动查看消费曲线、额度和模型明细。

顶部另有 **「自然／最近」** 选择，默认使用自然日历模式，并记住上次选择。「最近一天／最近一周／最近一个月」分别统计截至当前时间的过去 **24 小时／7 天／30 天**，最近一个月固定为 30 天。最近模式显示实际起止时间，日期翻页与日期选择停用；点击「当前时间」重算区间，手动或自动刷新也会更新区间。切回自然模式恢复日期导航。

- **消费／产出**：启动默认显示消费。可点击标签、卡片标题旁的左右箭头，或在卡片内左右拖动切换；点击卡片后可用键盘左右键，也支持 Shift + 滚轮。两页共用布局，高度相同，切换时下方区域不跳动。普通刷新、日期及日／周／月切换保留当前页。
- **产出内容**：改动行数（新增 + 删除）、新增行、删除行、修改文件数和完成轮次。只使用 Codex 自带日志，不接入 Issue/MR 或外部平台；没有记录的时段显示 `—`。

- **周视图**：自然周，周一至周日；每个点为一个小时内的 Token／美元费用。
- **月视图**：自然月；每个点为一天内的 Token／美元费用。
- **最近视图**：最近一天／一周按北京时间整点分小时，最近一个月按北京时间日期分天。首尾时段裁剪到实际区间，汇总、模型明细、产出和曲线使用同一次刷新时刻；悬停可查看裁剪后的时段，末段只计截至当前时间的记录。
- 两条曲线分别使用自己的纵轴，鼠标悬停或点击任一曲线可查看该时段的精确 Token 与美元数值。曲线表示各时段的用量，不是累计总量；过去无日志时段为 0，未来时段留空，当前时段标记「进行中」。
- 未知报价仍计 Token，费用曲线显示已知价小计，以虚线、空心点和 `*` 提示缺价。价格编辑以 **美元 / 每百万 token** 为单位，修改后区间总额与曲线一起重算。
- **模型明细**：一次展示一个模型，使用标题旁的左右箭头翻页，页码表示当前位置。Fast / Priority 用量按 `模型 · FAST`、Ultrafast 按 `模型 · ULTRAFAST` 分别单独列卡，普通用量保留原模型名；刷新后保留正在查看的模型；当前区间不再包含该模型时回到第一张。
- 右侧滚动条按需显示：内容放得下时隐藏并释放占用宽度，窗口缩小或内容变长时自动恢复。
- **账号额度**：用标题旁的左右箭头翻账号，每次只展示一个。当前登录账号固定第一页，其余账号按各额度窗口中最早的重置时间升序；时间未知排最后。普通刷新保留正在看的账号，登录发生切换后回到新的当前账号。
- 启动和手动刷新立即读取本机用量、识别当前登录并查询账号额度；自动刷新对齐北京时间的每 5 分钟刻度，例如 1:43 启动后在 1:45、1:50 更新。手动刷新不会移动自动刷新时间，页脚显示下一次更新时间。休眠期间不更新，恢复后补一次并重新对齐钟点。
- 其他账号展示上次成功查询的本地快照，需在 Codex 中各登录一次并让便签查询成功，才会加入列表。翻页只查看，不会切换 Codex 登录。
- 过期快照显示「已到重置时间 · 待刷新」，不会推算成满额；未知窗口、比例或时间也不按 0 处理。不推断 Pro 的 X5 / X20 档位。
- 按你的显示偏好隐藏 Spark 的 5 小时与每周额度，以及 gpt-reserve（base_model_inference）额度；这些隐藏额度的重置时间也不参与账号排序。

## 统计口径

- 产出读取 Codex 原生 `item_completed / FileChange` 的成功完成记录，以及 `task_complete` 完成轮次。失败修改、中断事件及 `codex-auto-review` 不计入；复制、分叉、归档的相同事件只计一次。按完成事件的北京时间归入日／周／月，修改文件数在所选时段按规范化路径去重。
- 改动行数包含代码、文档及其他文本；同一行反复修改会累计，**不是 Git 净增行数或最终代码规模**。终端脚本等写入若没有内置文件修改记录，无法计入。完成轮次是日志记录的轮次结束，不表示任务验收通过。界面展示本机日志能确认的产出小计。
- 按用户指定口径排除 `codex-auto-review`：不计入任何日期的 token、美元金额和模型明细；原始日志保留。这是便签的统计范围设置，不代表对该模型官方收费政策的判断。
- 只读 `$CODEX_HOME/sessions` 和 `archived_sessions` 中的 `.jsonl` 与 `.jsonl.zst` 日志；未设置该环境变量时使用用户目录下的 `.codex`。Codex 将旧日志压缩后仍可计入，不会把压缩文件解包落盘或修改原始记录。统计包含当前电脑保存的历史和归档记录，不能按切换过的 Codex 登录账号拆开，也不含其他电脑或未同步的云端任务。
- 按用量事件发生时间换算到 **北京时间（固定 UTC+8）** 分日，而非按任务创建日期。跨日任务会分别计入对应日期；自然周从北京时间周一 00:00 开始，自然月从每月 1 日 00:00 开始。
- 最近范围按日志记录的精确用量事件与产出完成事件时间筛选，**包含区间起点、不包含终点**。累计用量仍先经过相同的去重和差值处理，再归到记录时间；不按任务创建时间或运行时长跨时段分摊。最近范围使用缓存中已有的精确时间戳，缓存结构无需迁移；CLI 的 `--report` 和 `--date` 继续使用原有报告格式与自然日期筛选。
- 日期导航、曲线、额度快照／重置时间和刷新时间均使用北京时间，不受 Windows 时区或夏令时影响。历史记录也按 UTC+8 重新分日、分小时，原始日志保持不变。
- 「输入」是总输入减去缓存读取；「缓存」指缓存读取；「输出」已经包含推理输出。三者相加就是 token 总量。
- 如果日志记录缓存写入，它是「输入」的子项，不再次加入总 token；计费时从普通输入中剔除，按缓存写入价计费。
- 用量事件通常是累计快照，不能直接相加。读取器处理重复快照、累计重置、追加内容、归档移动和分叉复制。分段首条含历史基线时，只统计可确认的本次用量，并给出数据提示。日志不完整时无法重建遗失的使用量。
- 账号额度查询核对响应账号 ID、本机登录 ID 与查询前后身份，匹配才保存。每个账号保留自己的「通用额度」和「GPT-5.3-Codex-Spark」窗口；查询失败保留该账号上次快照与时间。接口依据 [官方 App Server 文档](https://learn.chatgpt.com/docs/app-server) 与本机生成的协议 schema，并已实测 `accountId` 归属字段。
- 模型行按日志里的 `service_tier` 分组；读取器支持 `thread_settings_applied`、`token_count.info` 和 `turn_context` 中的设置。`fast` 与已更名的 `priority` 归入 FAST，`ultrafast` 归入 ULTRAFAST，其余归入普通。同一日志的后续轮次或部分设置省略速度字段时，沿用最后明确设置；显式 `default` 或 `null` 切回普通，始终没有速度信息的日志也归普通。模型明细、CLI 报告、自然与最近范围汇总及曲线都保持这三个变体分开。更新后自动重新解析旧版缓存，修正被误归普通的历史用量，无需手动重建；Token 数保留原始记录，不乘速度倍率。
- 界面额度唯一来源是已核对账号 ID 的接口快照。原有日志没有账号 ID，日志额度不进入账号展示，也不作为查询失败时的替代数据；移除原来的「未归属日志额度」。没有该账号快照时显示暂无数据。Token、美元总额和模型明细仍包含本机全部日志，不随账号额度翻页变化。额度百分比不会换算成美元；CLI 本地报告仍保留原始日志额度元数据供诊断。

## 美元金额代表什么

金额是 **API Standard 短上下文刊例价估算，Fast / Priority 按 2.5 倍、Ultrafast 按 8 倍换算，非订阅账单或实际扣费**。已核实价格保存在 `prices.json`，来源和限制见 [价格来源说明](docs/pricing-sources.md)。历史日期也按这份当前价格表估算；没有历史逐次生效价格表。

速度倍率沿用官方**订阅内额度**口径：Fast / Priority 为 2.5 倍，Ultrafast 为 8 倍；官方**购买 credits / 企业按量付费**倍率则为 2 倍、6 倍，API key 使用独立的 API 价格。本便签沿用订阅内额度倍率作美元展示估算，无法按日志判断每次使用来自哪类额度，不自动切换计费口径。[官方 Speed 说明](https://learn.chatgpt.com/docs/agent-configuration/speed)

各速度变体分别计价，普通输入、缓存读取、缓存写入和输出均乘对应倍率；同时不含长上下文、工具、图像、语音和地区处理等单独费用。没有公开同名价格的模型不猜价：保留 token，并标明金额是已知价格的小计。手动报价可以覆盖内置价格；缓存写入单价未知且存在写入用量时，金额同样按部分已知处理。

## 本地数据

会话解析默认使用 **SQLite 持久缓存 + 进程内存缓存**，文件为项目 `.local/usage-cache.sqlite3`（当前为 `D:\genrain\codexUsage\.local\usage-cache.sqlite3`）。首次启动全量读取 `sessions` 与 `archived_sessions`；以后启动先显示缓存中的历史，再检查日志变化。按规范化后的 Codex 数据目录隔离缓存，不按登录账号拆分历史。

启动、手动刷新和自动刷新都会枚举文件检查变化。未变化的文件复用已解析事件；从磁盘恢复时会校验短文件头与读取边界摘要；追加文件只解析新增完整行，未写完的半行留待下次；检测到替换、改写或截断时重读该文件。归档移动按新路径重读，并移除旧路径贡献；确认删除的源文件不再计入。每次仍对事件重新去重、汇总，缓存不是原始日志的永久备份。局部摘要不等于全文件校验，无法保证识别刻意保留文件信息及校验片段的中段改写；怀疑统计异常时可主动重建。

压缩日志流式解码，沿用相同的事件去重和分日逻辑；同路径的明文与压缩副本同时存在也不会重复计数。压缩文件变化后整文件重新解码，未变化时直接复用缓存；损坏、截断或读取中改写时保留上次完整快照并提示重试。解析器升级会自动重建相应来源缓存，首次补读压缩历史可能耗时较长，后续刷新复用解析结果。

读取失败或目录扫描不完整时，保留上次完整结果并提示未更新。事件与读取检查点在同一事务提交；异常退出后从上次提交处继续。缓存损坏会尝试安全隔离并重建，版本不兼容时重建对应来源或降级；只读、被占用或无法写入时仍可在内存中统计，之后重试保存。多个实例通过数据库事务及修订号校验避免旧结果覆盖新结果。

点击刷新旁的 **「⋯ → 重建缓存」** 可从全部原始日志重新生成缓存，不删除或修改源日志；也不会改变五分钟自动刷新计划。说明弹窗显示缓存路径、复用／增量／重读文件数、读取字节数与耗时。价格独立于缓存，修改价格只重新计算金额，不需要重读日志。

Token 计量读取本机日志元数据；产出计量在本机解析原生文件修改记录，产出汇总仅保留行数、完成轮次和用于文件去重的路径哈希，不保留文件正文、补丁或对话。持久缓存还保存日志路径、工作目录、会话／轮次标识、模型、累计计数与续读位置等必要元数据；日志校验只保存摘要。缓存不保存登录凭据，不上传对话。桌面界面读取当前 Codex 目录的 `auth.json` 中的账号显示元数据，通过已安装的 `codex.exe app-server --stdio` 查询账号额度；由 Codex 使用当前登录访问官方服务，不启动模型任务或切换账号。每次查询使用隐藏临时进程，失败或超时会退出。

账号 ID 只保留 SHA256 标识；邮箱、套餐、快照时间与额度窗口保存到 `.local/account-quotas.json`，不保存原始账号 ID、JWT、访问或刷新凭据。窗口设置与价格也保存在项目 `.local/`。便签不写回 Codex 登录文件或原始日志。纯计量命令 `--report` 不读取账号、不联网、不输出邮箱。

## 开发与验证

使用 Python 3.11+（含标准库 Tkinter）与 `zstandard==0.25.0`，后者用于读取 Codex 的压缩历史日志，依赖声明在 `pyproject.toml`。当前项目已创建独立 `.venv`，所有依赖、脚本和测试使用这个环境。

```powershell
# 在另一台电脑上首次准备环境
py -3 -m venv .venv

# 安装项目声明的压缩日志依赖（已有环境升级时也执行一次）
.\.venv\Scripts\python.exe -m pip install zstandard==0.25.0

# 开启桌面窗口
.\.venv\Scripts\python.exe app.py

# 查看纯用量与价格 JSON，不开启窗口
.\.venv\Scripts\python.exe app.py --report --date 2026-09-13

# 指定其他本地 Codex 数据目录
.\.venv\Scripts\python.exe app.py --codex-home D:\another-codex-home

# 强制重建当前 Codex 数据目录的历史解析缓存
.\.venv\Scripts\python.exe app.py --report --rebuild-cache

# 本次绕过持久缓存，便于对照全量读取结果（不改已有缓存）
.\.venv\Scripts\python.exe app.py --report --no-cache

# 运行测试
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

布局回归默认跳过，避免测试时弹窗；需要检查界面时，在运行测试前显式设置 `$env:CODEX_NOTE_GUI_TESTS = '1'`。它会短暂打开独立测试窗口。

若无控制台启动失败，查看 `.local/app-error.log`。没有设置开机自启动。
